## Задача. Выпуклые многоугольники

Реализовать класс выпуклых многоугольников на плоскости:

1. Операции: пересечение, проверка на нахождение внутри, триангуляция.
2. Методы: площадь и периметр.
3. Проверка выпуклости при инициализации из списка вершин.

## Что было сделано

- Реализован класс `ConvexPolygon` для выпуклых многоугольников.
- При создании проверяется корректность и выпуклость многоугольника.
- Добавлены вычисляемые свойства площади и периметра.
- Реализованы проверка положения точки, пересечение многоугольников и триангуляция.
- Добавлен `demo.py` с примером работы класса.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не используются.

```bash
python3 demo.py
```

Вершины нужно передавать в порядке обхода границы. Если пересечение не имеет площади, `intersection` возвращает `None`.
